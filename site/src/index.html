      Render your footage

      The browser runs the same Rust code as the command-line renderer, so this command reproduces what you see, at full length and with sound.

      To use a downloaded preset, pass it as bender --preset bend.json -i input.mp4 -o bent.mp4. Output is H.264 MP4, FFV1 MKV or PNG, chosen by file extension. Get the bender command from the latest release; it needs GStreamer installed.

      bender-rs is a Rust effect core with a GStreamer renderer, a command-line tool and a desktop app. Licensed MIT or Apache-2.0. Source on GitHub.
